# Calculadora

## Descripción
Calculadora de consola en Python que permite realizar operaciones matemáticas básicas y avanzadas desde un menú.

## Operaciones y estados

| N.º | Operación | Estado |
|-----|-----------|--------|
| - | Suma | ✅ Completada |
| - | Resta | ✅ Completada |
| - | Multiplicación | ✅ Completada |
| - | División | ✅ Completada |
| 1 | Potencia | ⏳ Pendiente |
| 2 | Módulo | ⏳ Pendiente |
| 3 | Raíz cuadrada | ⏳ Pendiente |
| 4 | Porcentaje | ⏳ Pendiente |
| 5 | Valor absoluto | ⏳ Pendiente |
| 6 | Factorial | ⏳ Pendiente |
| 7 | Promedio | ⏳ Pendiente |
| 8 | Redondeo | ⏳ Pendiente |
| 9 | Validación de entradas | ⏳ Pendiente |
| 10 | División por cero | ⏳ Pendiente |
| 11 | Mejorar el menú | ⏳ Pendiente |
| 12 | Repetir operaciones | ⏳ Pendiente |
| 13 | Historial de operaciones | ⏳ Pendiente |
| 14 | Limpiar historial | ⏳ Pendiente |
| 15 | Mejorar documentación | ⏳ Pendiente |
